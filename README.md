# Climb-Logger
A website where climbers can keep track of their topped climbing routes and see their progression over time

## Functions
- a login page
- sign up page
- statistics page where you can see you top 10 hardest routes, and total routes climbed per grade
- page for adding more climbs

## How to install
import the whole project by downloading the zip
use the import.sql in the database map to create the database in MySQL

### Techniques used:
- php used as main coding language
- MySQL for the database
- javascript for the json data and the chart.js library
- html/css with some bootstrap for the visuals
